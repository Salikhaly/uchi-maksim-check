02 · рабочая связка

СПИН → Боль → СПВ

Здесь не отдельные списки вопросов и решений. Менеджер идёт по исходной цепочке СПИН, фиксирует реальную боль клиента и только после этого выбирает соответствующее решение из базы СПВ.

Как работать: выбери цепочку слева → задай вопросы по порядку → посмотри, какую боль нужно подтвердить → выбери боль → используй соответствующее СПВ. Не презентуй решение до подтверждения проблемы.
